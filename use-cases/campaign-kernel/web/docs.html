CampaignKernel Documentation

CampaignKernel is an Agent Kernel powered campaign production system for student clubs, NGOs, volunteer groups, and event teams. It works through Telegram and the web workspace using the same tools, state, approvals, flyer renderer, SDG intelligence, and report generator.

Core Flow

  1. Create an event context with brand, theme, colors, hashtags, and sample captions.
  2. Upload sample flyers in Telegram or add sample flyer notes in the web workspace.
  3. Send a short brief and review the structured content draft.
  4. Generate the campaign pack: flyer, captions, SDGs, impact goals, variants, and quality score.
  5. Approve, mock publish/export, and create the impact report.

Agent Roles

Event context, flyer content, flyer design, caption, approval, publishing, strategy, and memory agents coordinate through typed tools. The strategy agent handles SDG classification, impact goals, accessibility, audience variants, platform variants, quality scoring, and judge reports.

Free Production Mode

The default flyer mode is the deterministic template renderer, mock publish is enabled, and WhatsApp is an export package. Live social publishing and AI image generation stay optional behind environment flags, so the competition demo remains reliable without paid extras.

VM Checklist

Set the OpenAI or Azure OpenAI variables, Telegram bot token, webhook secret, persistent state directory, and mock publish flag. Run uv run python ops/doctor.py, start uv run python server.py, expose port 8000, set the Telegram webhook, then confirm /campaign/ready.
